# Saito - 小説投稿サイト

シンプルな小説投稿サイトです。トップページ・作品詳細・話を読むページと、
管理者専用の投稿画面・ホーム画面設定を備えています。

## 構成

```
index.html / novel.html / episode.html   … 公開ページ（サーバーのAPIからデータを取得して表示）
signup.html / login.html / mypage.html   … 読者向けページ（会員登録・ログイン・ブックマーク一覧）
404.html                                 … 存在しないページにアクセスしたときの共通エラーページ
js/reader-nav.js                         … 公開ページ共通のヘッダーナビゲーション（ログイン状態表示）
css/style.css                            … 共通スタイル（水色×黒の2トーン）
admin/                                   … 管理画面（ログイン・小説投稿・投稿の管理・ホーム画面設定・アカウント設定）
server/                                  … Node.js + Express の簡易バックエンド
data/                                    … 投稿データの保存先（初回起動時に自動生成。gitには含めない）
```

投稿データ・サイト設定は `data/` 以下のJSONファイルに保存されます（簡易的な永続化です。
本格的な運用ではSQLite等のデータベースへの置き換えを推奨します）。

## セットアップ

```bash
npm install
npm start
```

起動後、ブラウザで `http://localhost:3000` を開いてください。

## 管理者ログイン

初回起動時に、以下の管理者アカウントが自動的に作成されます（起動時のログにも表示されます）。

- ID: `admin`
- パスワード: `change-this-password`

管理画面へは `http://localhost:3000/admin/login.html` からアクセスできます
（公開ページにはリンクを置いていません）。

**⚠️ このパスワードは初期セットアップ用の仮のものです。** ログイン後、管理画面の
「アカウント設定」から必ず変更してください。

## できること

- ホーム画面：投稿された作品の一覧表示、キーワード検索、タグ絞り込み、もっと見る（ページング）
- 作品詳細ページ：あらすじ（備考）、タグ、目次、ブックマーク
- 話を読むページ：文字サイズ切り替え、前後の話への移動
- 読者機能：会員登録・ログイン・ブックマークした作品の一覧（マイページ）
- 管理画面：
  - 新しい小説の投稿（タイトル・著者名・作品タイプ・備考・タグ最大10個・第1話の本文）
  - 既存の小説への話の追加
  - 投稿済み作品・話の編集／削除（投稿の管理）
  - ホーム画面の表示設定（サイトタイトル・表示件数・並び順・タグ検索候補）
  - 管理者パスワードの変更（アカウント設定）

## セキュリティ対策

- パスワードは bcryptjs でハッシュ化して保存
- `helmet` による基本的なセキュリティヘッダーの付与
  （各ページがscriptタグを直接埋め込んでいるため、CSPのみ無効化しています）
- ログイン・会員登録エンドポイントに `express-rate-limit` による回数制限
  （同一IPから15分間に20回まで）を設定し、総当たり攻撃を軽減
